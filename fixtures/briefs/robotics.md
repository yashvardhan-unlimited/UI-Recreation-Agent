# Robotics landing-page acceptance brief

Create a premium but credible single-page website for **Axiom Robotics**, a fictional company building dexterous warehouse robots for mid-market logistics teams.

Audience: operations leaders and automation engineers evaluating a pilot.

Required content: concise hero, measurable operating proof, three capability stories, deployment process, safety statement, customer quote using clearly fictional copy, and a pilot-request CTA with client-side validation and success state.

Required interactions: working mobile navigation, keyboard-accessible capability tabs, reduced-motion-aware entrance transitions, and a form that never submits to a backend.

Success: distinctive approved visual direction, useful at 390/1024/1440 widths, no horizontal overflow or broken controls, strict build/lint/typecheck/tests pass, axe has no serious/critical violations, and screenshots plus browser evidence exist for all default viewports.
