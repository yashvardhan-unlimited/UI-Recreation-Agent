# Preset: Editorial serif

## Theme
A well-edited printed magazine: generous margins, confident headlines, quiet paper tones. Reading comes first; decoration is rare and deliberate.

## Color
- bg #f7f4ee (warm paper), fg #1c1a17 (ink), muted #5e584f, surface #eee8de, line #d8d0c3.
- accent #9a3412 (rust), used for links, rules and one primary action per screen.
- No gradients. Images carry the color; the interface stays neutral.

## Typography
- Display: a high-contrast serif (e.g. Fraunces, Playfair Display). Body: a readable serif or humanist sans (e.g. Source Serif 4, Inter).
- Headings large and tight: text-5xl/md:text-7xl, leading-tight, normal weight.
- Body 17–19px, max-w-prose, leading-relaxed. Small caps or uppercase tracking for labels.

## Components
- Pull quotes set in the display face with a thin accent rule above.
- Numbered chapter labels ("01 — Origins") above section headings.
- Images full-bleed or aligned to the text column, never floating in cards.
- Buttons: text links with an underline offset; one solid accent button for the main action.

## Layout
- 12-column grid with an offset reading column; asymmetric, left-aligned.
- Alternate wide image sections with narrow text sections.
- Vertical rhythm: py-24 to py-32 between sections.

## Motion
- Calm. TextReveal on the hero headline, Reveal on paragraphs, slow Parallax on one large image.

## Do / Don't
- Do let whitespace and type size create hierarchy.
- Don't use cards, pills, icons in circles or centered marketing blocks.
